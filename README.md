# Buds Battery Dock

一个**非官方、非商业**的 Android 耳机电量工具。通过 BLE 或经典蓝牙 SPP 读取部分耳机的左耳、右耳和充电仓电量，在通知栏和桌面仪表盘显示。

> 本项目与任何耳机品牌及其关联公司都没有关系，也未获得其授权或认可。所有商标归各自所有者。

## 功能

- 左耳 / 右耳 / 充电仓电量
- 通知栏常驻（可在设置关闭）
- 单耳未佩戴或未上报时显示 `—`，不误报 0%
- 仓盖关闭后保留最后电量，标注「关盖前」
- 可选仓电量估算（默认关闭，按「耳机在仓 / 不在仓」分别学习；仅供参考）
- 连接/断开事件驱动，未连接时自动清理通知
- 单 Activity、无 AndroidX、无广告、不联网、无统计 SDK

### 安装注意

- Android 8.0（API 26）及以上
- 首次安装需允许“未知来源”安装
- 包名是 `com.openbuds.batterydock`
- 如果你之前装的是旧包名 `com.ruoshui.batterydock`，**不能直接覆盖**：
  - 新版会作为独立应用安装
  - 需要重新授予蓝牙/通知权限
  - 需要重新选择一次耳机
  - 旧版可以保留或卸载
- 安装后先在系统蓝牙里配对耳机，再打开应用选择设备
- Furina 使用经典 SPP；如果官方 RoseLink 正在后台占用串口，请先强制停止它

## 首次启动

1. 打开应用，允许「附近设备」和「通知」权限
2. 打开耳机仓盖，让耳机进入配对/连接状态
3. 点「切换耳机」，选择系统蓝牙里已经配对的耳机
4. 等待通知栏出现电量；如果没出现，点「立即刷新」
5. 若系统弹出电池优化/自启动提示，建议允许

首次授权后，应用会自动启动后台服务；如果授权弹窗被拒绝，需要到系统设置里手动打开权限。

## 后台清理与白名单

这是 Android 和手机厂商的策略，应用无法完全绕过。

- 从「最近任务」把应用划掉，部分系统会**连前台服务一起杀掉**
- OPPO/ColorOS、vivo/OriginOS 的「一键清理」「深度清理」也可能杀掉后台
- 被杀后通知栏电量会消失，重新打开应用才会恢复

建议在系统设置里：

- 允许应用「自启动」
- 电池优化设为「不限制」/「允许后台活动」
- 在最近任务里锁定应用（如果系统支持）
- 不要把本应用加入“睡眠/深度睡眠”名单

应用内「设置 → 后台运行」可以打开电池优化和自启动设置页面。即使全部设置，厂商的强制清理仍可能生效，这是系统限制。

## 兼容性

目前实现的是协议级兼容，不是“所有品牌通用”：

- BLE：`00FE / F1 / F2` 私有电量帧，标准 `180F / 2A19`
- 经典 SPP：`rs-common-v2` 属性查询（含 Furina 的完整查询）
- 已实测：Furina、BudsFeel MK2
- 其他型号只有在使用相同协议时才可能工作

不同品牌的私有协议、加密和属性 ID 不同，不能保证适配。

## 构建

不使用 Gradle，直接调用 Android SDK 的 `aapt2`、`javac`、`d8`、`zipalign`、`apksigner`。

要求：

- Windows + PowerShell
- JDK 17（`javac` 在 PATH）
- Android SDK：`build-tools;35.0.0` 或兼容版本，`platforms;android-35`

默认脚本会从 `..\.android-sdk` 查找 SDK。目录不同请修改 `build.ps1` 顶部的 `$sdk`。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物：

```text
build/openbuds-battery-2.0.1.apk
```

首次构建如果没有 `keystore/`，脚本会用 `keytool` 生成一个本地开发签名。**不要把 `keystore/` 提交到仓库**；正式发布请使用自己的签名密钥。

更完整的构建说明见 [BUILDING.md](BUILDING.md)。
