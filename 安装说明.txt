Buds Battery Dock 2.0.1 · 安装与使用说明
====================================

适用品牌：弱水时砂 / Rose Technics / RoseLink 生态的部分耳机。
已适配：Furina（芙宁娜·不休独舞）、BudsFeel MK2。
兼容不等于官方支持，其他型号需使用相同协议。

一个非官方耳机电量工具。与任何耳机品牌都没有隶属或授权关系。

一、安装
--------
1. Android 8.0 及以上。
2. 安装 openbuds-battery-v2.0.1.apk，首次需允许“未知来源”。
3. 包名是 com.openbuds.batterydock。
4. 如果之前装的是旧包名 com.ruoshui.batterydock，不能覆盖安装：
   - 新版会作为独立应用安装；
   - 需要重新授予蓝牙和通知权限；
   - 需要重新选择一次耳机；
   - 旧版可保留或卸载。

二、首次启动
------------
1. 打开应用，允许“附近设备”和“通知”权限。
2. 在系统蓝牙里配对耳机（媒体音频已连接即可）。
3. 打开耳机仓盖，点“切换耳机”选择设备。
4. 等通知栏出现电量；没有出现就点“立即刷新”。
5. 如果系统提示电池优化/自启动，建议允许。

首次授权后会自动启动后台服务；拒绝了权限要到系统设置里手动打开。

三、后台与白名单（重要）
------------------------
从“最近任务”划掉应用，部分系统会连前台服务一起杀掉；OPPO/ColorOS、
vivo/OriginOS 的“一键清理/深度清理”也可能杀掉后台。应用无法完全绕过。

建议：
- 允许“自启动”；
- 电池优化设为“不限制/允许后台活动”；
- 在最近任务里锁定应用（如果系统支持）；
- 不要把应用加入睡眠/深度睡眠名单。

应用内“设置 → 后台运行”可以打开电池优化和自启动设置页。
即使全部设置，厂商强制清理仍可能生效，这是系统限制。

四、连接与通知
--------------
- 未连接时通知最多显示 10 秒；离开应用会立即移除；
- 已连接时通知显示左/右/仓电量；
- 单耳未佩戴或未上报显示“—”；
- 仓盖关闭后显示“关盖前”，开启估算后显示“估算”；
- 估算仅供参考，以实际为准。

Furina 使用经典 SPP。如果官方 RoseLink 在后台占用串口，请先强制停止它。

五、下载困难
------------
GitHub 在部分地区可能打开慢、下载中断或无法直连，这是网络问题，不是
安装包损坏。可以换网络、用浏览器下载、通过可信代理访问，或下载源码自行构建。

请不要从来路不明的网盘或“破解站”下载 APK。唯一发布位置是 GitHub Releases，
其他人转发的安装包无法保证未被修改。

六、源码构建
------------
需要 Windows、JDK 17、Android SDK build-tools 和 android-35 平台。
不使用 Gradle。详细步骤见 BUILDING.md。
